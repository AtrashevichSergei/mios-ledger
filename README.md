# MIOS · журнал агента каскада

Публичный якорь торгового журнала агента MIOS. Агент торгует правило «каскад принудительных
закрытий возвращается» на демо-счёте BingX VST (виртуальные деньги, реальные цены) и пишет
каждое решение — вход, выход, пропуск, ошибку — в журнал.

- Витрина: https://cascade-agent.fly.dev/public
- Сырой журнал: https://cascade-agent.fly.dev/public/ledger.jsonl

## Как это доказывает, что журнал не переписан

Строки журнала сцеплены хешем: `h₀ = ""`, `hᵢ = sha256(hᵢ₋₁ + строкаᵢ)`.
Каждые 6 часов GitHub Actions этого репозитория скачивает журнал, проверяет, что он
совпадает со **всеми** прошлыми якорями, и коммитит новый (`len`, `tip`) в `anchors.jsonl`.
Время коммита ставит GitHub, а не мы. Изменить, удалить или вставить любую прошлую строку
незаметно нельзя: вершина на заякоренной длине перестанет совпадать, и прогон упадёт.

Проверить самому (только стандартная библиотека Python):

```
git clone https://github.com/AtrashevichSergei/mios-ledger && cd mios-ledger
python3 verify.py
```

## Чего это не доказывает

- Что журнал полон: агент мог не записать сделку. Сделки сверяются с биржей только у владельца счёта.
- Ничего о строках до первого якоря, кроме того, что с момента якоря они не менялись.
- Что результат повторится. Это форвард одного правила, а не обещание доходности.
